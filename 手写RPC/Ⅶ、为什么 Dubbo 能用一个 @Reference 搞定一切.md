# 二、设计决策1：为什么需要加拦截器
问题：日志、耗时、参数校验这些"横切关注点"，如果散落再代码层，代码会很混乱
没有拦截器
```java
public Object invoke(...) {
    log.info("调用开始");
    long start = System.currentTimeMillis();
    try {
        Object result = doInvoke(...);
        log.info("调用成功，耗时 {}", System.currentTimeMillis() - start);
        return result;
    } catch (Exception e) {
        log.error("调用失败", e);
        throw e;
    }
}
```
问题：
* 日志、耗时、校验、监控全堆再一起
* 想加一个鉴权，又要改代理层代码
* 关注点没有分离
